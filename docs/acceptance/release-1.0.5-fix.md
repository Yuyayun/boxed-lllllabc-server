# 1.0.5-fix 正式发布核对

日期：2026-11-26。前后端统一为 `1.0.5-fix`，将此前 fix.1、fix.2 及候选回复收尾补修合并发布。前端从 `codex/1.0.5-indexeddb-recovery`、后端从 `codex/1.0.5-log-hardening` 快进合并到各自 `main`，配套附注标签 `v1.0.5-fix` 和正式 GitHub Release。

## 内容与兼容

- 改善正常回复、流式结束和候选回复的保存核对，补记生成中切后台再返回时的中间状态，保留原有未保存变更保护。
- 改善旧记录的连续内容恢复、完整分支选择、待确认提示和恢复过程日志。
- 修复浏览器本地备份目录与事务异常处理，提供有限读取重试、只读救援和明确确认后的清除重建。
- 在前端存储设置中显示后端实际返回的版本，合并并简化内置更新日志。
- 后端同步 35 份共享模块及必要依赖，来源提交在 `vendor/frontend/ORIGIN.json` 记录；许可证保持 CC BY-NC-SA 4.0。

正常更新保留已有备份，无需清库或重新迁移。IndexedDB 9、SQLite schema 4、协议 6 与待确认记录格式不变。前端可继续搭配后端 1.0.5 使用，完整的恢复过程日志建议前后端配套更新。后端更新后需重启酒馆，前端更新后需刷新网页。

更新不会直接核销无法证明已经处理的旧记录。确认当前聊天与所有候选完整后，可先创建当前聊天快照，再预览并明确确认恢复这份快照；随后仍需核对酒馆文件和对应备份，不能仅凭当前页面相同就清空记录。

原生旧版本回归固定读取 `v1.0.5` 提交，避免发布副本更新后误将新代码作为历史基准。自动化仅使用隔离合成数据，不操作用户原库；这些结果不替代 Termux、iOS Safari、系统真实挂起或用户设备容量的全面验收。

## 安装包与发布核对

- 前端：`boxed-lllllabc-v1.0.5-fix.zip`，解压后的 `boxed-lllllabc` 放入酒馆 `public/scripts/extensions/third-party`。
- 后端：`boxed-lllllabc-server-v1.0.5-fix.zip`，解压后的 `boxed-lllllabc-server` 放入酒馆 `plugins`。
- 两端各附 `SHA256SUMS.txt`。安装包从最终提交按运行文件清单生成，逐文件与 Git 内容比较，检查路径、模块依赖、版本及许可证；上传后下载核对字节和 SHA-256。
- 测试、私人附件、需求草稿、PRODUCT.md、本地运行时、日志与数据库不进入安装 ZIP。前端救援说明和只读救援工具随包提供。

精确提交号、附注标签及附件哈希以 Git 历史、正式 Release 和附件校验文件为准；发布核对要求开发分支、main、标签解引用及安装包来源一致。原始发布脚本和验证回执保存在本地 `.local-test/release-1.0.5-fix-20261126`。
