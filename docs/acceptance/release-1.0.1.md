# 1.0.1 正式发布核对

日期：2026-10-29。按使用者授权，将前后端各自的 `gpt/1.0.1-migration` 合入 main，并创建 `v1.0.1` 正式标签及 GitHub Release。两个仓库继续独立维护。

## 发布内容

- 功能代码以已验收开发分支为基础，包含最新手机弹窗布局及四种快照操作的统一成功收尾。
- 本次发布整理只调整正式安装说明、当前公告及验收索引，不增加功能。
- manifest、package、前端设置、当前公告及后端状态版本均为 1.0.1。配套存储协议 6、分批迁移版本 3；25 个共用模块逐字节一致，后端保留原有已验证来源提交。
- README 安装入口改为 main；历史阶段文档保留当时的开发版本及未发布说明。
- 不提交原始需求、运行时、数据库、浏览器资料、原始测试日志或截图。

## 验证依据

- 本次正式发布前重跑前端现有自动化测试，313/313 通过；后端 Node 22.14.0、24.22.1 各 137/137 通过。
- 最近界面改动的实际宿主显示与触屏模拟结果见[前端手机弹窗与快照交互收尾](https://github.com/Yuyayun/boxed-lllllabc/blob/v1.0.1/docs/acceptance/1.0.1-mobile-snapshot-ui.md)：三个手机尺寸、桌面尺寸及 12 项快照交互检查通过，无页面错误。
- 日志限频、空闲提示及版本检查见[发布前四项收尾](1.0.1-pre-release-finishing.md)。
- 大规模数据及专项兼容验收沿用此前结果，未重复执行；Termux 实机验收由使用者负责，本记录不将其标记为已通过。
- 第三组暂缓项 02、03、04、12 保持原样。迁移、保存、快照机制未在发布整理中改动。
