# 1.0.4 正文版本回归修复验收

日期：2026-11-21。从服务器 1.0.3 main（e72a078）创建 `codex/1.0.4-backup-version`，与配套前端完成修复与验收后共同发布 1.0.4。正式入口见[发布核对](release-1.0.4.md)。

## 实现

SQLite 普通事务不再依据“打开了哪些 store”推进正文版本。成功 put 标记对应类型，delete/deleteForChat 仅在确实删到记录时标记。每个事务同类型只推进一次，版本、记录和副本证明在同一事务中提交或回滚；保留旧全局 revision。

共享分批操作也统一观察正式正文 put/deleteChat。暂存、撤销、空提交及空删除不制造正文变化；正式写入和清理仍使旧 scope 失效。批量删除多个聊天的同类型记录只推进一次。SQLite deleteChat 返回实际删除数量，IndexedDB 使用游标删除成功数量，两端语义一致。

共用模块与前端同步。前端同时收窄动作读取依赖：完整预览只读 full + pending，恢复中心保留全部依赖；不涉及 full 的动作不比较无关 full 状态。涉及 full 的状态保护、实际正文变化拦截、三轮重读、迁移 epoch、原子 pending 副本核销等保持生效。

无 schema、协议或数据格式变更，不需要清库、重新迁移或覆盖冻结原备份。成功重复 put 仍属于记录 mutation，没有引入全库等值比对。
