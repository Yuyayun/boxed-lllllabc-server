# 1.0.1 发布前收尾核对

日期：2026-10-29。基于已完成的问题整改，仅处理用户指定的四项收尾。

## 改动范围

- 隐藏迁移、清空界面的正常空闲提示；处理数量、排队及异常提示仍保留，监控机制未改。
- 普通迁移进度日志同阶段至少间隔约 5 秒；写入与逐批核对视为同一搬运阶段。关键事件及时记录，界面逐步进度不受限频影响。
- 前端持续记录任务进度时，后端不重复记录普通工作进度；前端超过 10 秒未记录时，后端保留每 5 秒的进度回退。日志清理、错误反馈及持久化机制未改。
- 将当前内置公告整理为五条面向用户的说明；前端、配套后端及界面版本统一为 `1.0.1`。
