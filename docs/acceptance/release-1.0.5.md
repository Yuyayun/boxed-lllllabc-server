# 1.0.5 正式发布核对

日期：2026-11-25。前端从 `codex/1.0.5-empty-chat`、后端从 `codex/1.0.5-pending` 快进合并至各自 `main`，配套附注 Tag `v1.0.5` 与正式 GitHub Release。

## 发布内容

- 删除、编辑和继续聊天按事件发生时的内容分别记录，恢复结果遵循实际消息顺序；普通删除不额外复制整份聊天。
- 恢复前追加保护，恢复后重读酒馆实际文件并核对备份；失败、中断或切换聊天时保留待确认记录。
- 旧数据只在现有证据能唯一确认结果时恢复，缺失或歧义时保留记录并说明原因。
- 区分空聊天与没有打开聊天，调整保存和备份文案；存储恢复失败时允许暂时关闭提示，写入仍暂停，并可重新进入处理。
- 完善浏览器数据库排队打开、旧前端写入新版记录及前后端错开更新的错误提示。

实现基线为前端 `c40ca2f`、后端 `baa23ad`。发布整理只更新正式说明、内置公告、配套来源和对应元数据断言。前端 manifest/package/设置版本/内置公告与后端 package/status 均为 1.0.5，32 个共享模块与所记前端来源提交逐字节一致。

## 验证

发布前在独立发布副本中重跑：前端 392/392；后端 Node 22.14.0、24.15.0 各 170/170；SQLite 历史竞态及操作日志安全专项共 31/31，无跳过。真实 Edge 桌面及 360px 触摸模拟下，IndexedDB 每种宽度 40 项、HTTP/worker/SQLite 每种宽度 45 项通过。

此前同一实现的验证包含 SillyTavern 1.15.0、1.19.0 原生文件保存与恢复，3000/10000 条大聊天，旧记录恢复、部分核销、并发、重命名，以及更新顺序和故障弹窗退出。历史 1.0.0→1.0.1、1.0.0→1.0.5、1.0.1→1.0.5 的后端更新夹具，均确认已完成迁移不会重新搬运；合成遗留收尾记录不会覆盖目标后续新内容。详见[实现与验收](2026-11-24-pending-recovery.md)。

安装 ZIP 从最终提交按运行文件清单生成，逐文件比较 Git 内容，检查安全路径、JS 语法、相对模块引用、版本及许可证，附 SHA256。上传后重新下载并核对字节与哈希。测试、需求草稿、私人附件、本地运行时、日志及数据库不进入安装包。

## 正式入口与兼容

- [前端 1.0.5](https://github.com/Yuyayun/boxed-lllllabc/releases/tag/v1.0.5)：`boxed-lllllabc-v1.0.5.zip`，目录 `boxed-lllllabc`，放入酒馆 `public/scripts/extensions/third-party`；Git 安装使用 main。
- [服务器插件 1.0.5](https://github.com/Yuyayun/boxed-lllllabc-server/releases/tag/v1.0.5)：`boxed-lllllabc-server-v1.0.5.zip`，目录 `boxed-lllllabc-server`，放入酒馆 `plugins`。
- 两端各附 `SHA256SUMS.txt`；GitHub 自动源码 ZIP/TAR 保留完整源码与测试。

服务器备份请一并更新前后端。SQLite schema 4、协议 6 不变，原备份无需清库或重新迁移。浏览器数据库升至 9，只作兼容保护，不改写或删除旧记录；升级后不支持直接降回旧前端。1.0.0 使用协议 5，跨协议升级需同时更新前端；旧网页中的脚本与弹窗不会被后端更新替换。

## 边界

全部自动化使用隔离合成数据，没有操作日常聊天或用户备份库。真实 Termux、Safari、手机软键盘和用户现场原库未验证。截图中的历史 SQLite 工作线程退出原因尚缺少对应日志，本次故障界面补修不能当作其根因已被定位的证明。

发布不启动日常酒馆、不自动切换存储或迁移数据，不要求用户另跑测试清单。许可证保持 CC BY-NC-SA 4.0。
