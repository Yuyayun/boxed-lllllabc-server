# 欢迎页连接检查日志补充（1.0.3 开发分支）

用户反馈只停留欢迎页时出现耗时 51.4 秒的 `cancelled`。启动会检查服务器 `/status`，原格式没有识别 `_status`，显示成“日常备份操作”；路由错误又只记录为通用“备份请求”。原截图不足以确认具体 operation 或断连起因。

本次在路由错误中保留 `_status`，并在终端及配套前端明确显示“检查服务器存储”“本次连接检查已取消，可重新检查服务器连接”。写入取消仍提示核对结果；没有修改数据库启动检查、超时、取消和备份写入逻辑。

真实 HTTP 回归覆盖初始化等待期间的持续心跳、完成后返回状态、检查连接断开后的取消传递，以及下一次检查成功。数据库工作在这些路由测试中由可控 worker 替身实现，断连由测试注入，不能据此断定现场发生了相同断连。完整后端串行测试 148/148 通过，前端 348/348 通过。

尚未稳定复现用户手机欢迎页静置时的断连起因，不宣称已修复该现场问题。未访问真实聊天或备份库。配套详细说明在前端 `docs/acceptance/2026-11-20-startup-cancelled-investigation.md`。
